# Privacy Policy — ScrollCapture

**Effective date:** August 15, 2026

ScrollCapture is a local screenshot utility. Its single purpose is to capture the webpage the user explicitly selects and save that capture as an image on the user's device.

## Data collection

ScrollCapture does **not** collect, transmit, sell, share, or store personal data, browsing history, webpage content, screenshots, URLs, analytics, identifiers, or telemetry on any external server.

## Local processing

When the user clicks **Capture full page**, the extension temporarily accesses the active tab, scrolls it, captures visible portions of that tab, stitches those portions into an image in the browser, and saves the resulting PNG through Chrome's download functionality.

All screenshot processing occurs locally on the user's device.

## Permissions

- **activeTab:** Gives temporary access only to the tab on which the user invokes the extension.
- **scripting:** Allows the extension to inspect page dimensions, scroll the selected page, trigger rendering, and temporarily adjust capture-specific styles.
- **downloads:** Allows the generated screenshot to be saved to the user's device.

ScrollCapture does not request persistent access to all websites.

## Third parties

ScrollCapture contains no advertising SDKs, analytics SDKs, trackers, remotely hosted code, or third-party data processors.

## Changes

If this privacy policy changes in a way that affects data handling, the updated policy will be published with the project and reflected in the Chrome Web Store listing where required.
