# Security Policy

## Supported version

Security fixes are applied to the latest released major version of ScrollCapture.

## Reporting a vulnerability

Please report security issues privately to the project maintainer rather than opening a public issue containing exploit details.

Before publishing the repository, replace this paragraph with the maintainer's security contact email or private reporting URL.

## Security model

ScrollCapture intentionally:

- uses Manifest V3;
- requests no persistent host permissions;
- runs only after explicit user invocation;
- contains no remotely hosted executable code;
- sends no screenshot or page data to external services;
- uses no analytics or advertising SDKs.
